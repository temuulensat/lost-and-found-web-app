# Worldwide location data

The location database is built from the GeoNames geographical database:

- `countryInfo.txt`
- `admin1CodesASCII.txt`
- `cities500.zip`

Source: https://download.geonames.org/export/dump/

GeoNames data is licensed under Creative Commons Attribution 4.0. The local
`locations.sqlite` file is generated by running `build_locations.py` from the
project root. The application opens this database read-only; user reports
continue to be stored separately in the existing application SQLite database.
